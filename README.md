# fpl-price-change-predictor
 A data-driven project to predict FPL player price changes using transfer activity.

 The Problem
In Fantasy Premier League, player prices change daily based on transfer activity. Knowing when a player's price will rise or fall is crucial for making smart transfers and building team value. This project aims to predict these price changes using historical data and machine learning.

The Goal
Build a model that predicts whether a player's price will:
Rise (increase by £0.1m)
Fall (decrease by £0.1m)
Stay the same

Using data such as:
Net transfers (in vs. out)
Current ownership percentagex`
Recent form
Fixture difficulty

Tech Stack
Python — core language
Pandas & NumPy — data manipulation
Scikit-learn — machine learning models
Matplotlib — data visualization
FPL API — data source
Jupyter Notebooks — exploration and analysis
